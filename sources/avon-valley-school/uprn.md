# Identifier and coordinates

The [asset row](asset.md) assigns this exact UPRN. The October 2026
OS Open UPRN CSV contains the same string and an OS reference point of
**449485 E, 276539 N** in EPSG:27700. The point is about **12.1 m** from the
asset workbook's grid point. The identifier match is exact. The points are
different source observations.[^os-uprn][^wcc-asset]

The UPRN is an addressable-object identifier. Its OS reference point lies
about 59 m outside the [plan-derived red line](site.md#boundary-and-point-check).
The register and notice give a school address without an explicit UPRN
field. The school address supports the association with the case.
