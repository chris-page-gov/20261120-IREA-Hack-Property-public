# Licensing decisions

| Material | Rights and handling |
| --- | --- |
| Repository-authored notes | Approved for public reading in the reviewed public edition. No blanket reuse licence is granted over authored notes or third-party material; retain file-level provenance and do not imply that the Open Government Licence covers original project text. |
| Organiser’s unlisted Eventbrite listing and booking confirmation | Retain factual summaries for local use. Redistribution terms are unassessed. Keep the original correspondence and personal identifiers out of the repository. |
| Cabinet Office estate workbooks | The [publisher’s catalogue](https://www.data.gov.uk/dataset/a3ad62cf-d8a2-4d3b-b3c6-24c35c5e0f71/the-government-property-estate-including-buildings-and-land) states the UK Open Government Licence. The public static edition contains reviewed derived counts and the full 2,267-row provisional candidate register with Cabinet Office attribution and an OGL v3.0 link. Keep original downloads in Git-ignored storage. The source includes freeholds and leases, and the public-ownership assumption is labelled. |
| Other public references | Links and summaries only. Check any resource-specific terms before acquiring or redistributing data. |
| National and Warwickshire supporting snapshots | Local use. Apply the product-specific terms and attribution, including OS OpenData, ONS and Environment Agency terms. Generalised footprints have a separate provenance record from any licensed OS NGD geometry. |
| ONS December 2025 county and unitary boundaries | Public static map uses simplified display shapes and aggregate estate counts from open digital boundary data under OGL v3.0. Credit ONS and OS in the map and rights page. The full boundary archive stays in Git-ignored storage. [ONS digital boundary terms](https://www.ons.gov.uk/methodology/geography/licences/). |
| Local OS NGD building checks | The existing PSGA key is used only by the private loopback service for bounded, on-demand matching. The public static edition contains no licensed NGD feature body, key, or route to that service. Any external service or shared derivative needs separate rights and security review. |
| Tower Hamlets static notebook and UK deprivation reference | The public edition contains the reviewed open-data notebook, including the four-nation small-area rank and decile reference. Its source manifest records exact editions, download URLs and hashes. Attribute MHCLG, Welsh Government, Scottish Government and NISRA; avoid comparing absolute deprivation ranks between nations. ONS boundaries and OpenStreetMap tiles retain their separate credits. |
| Three slide photographs | The photographer, Chris Page, expressly approved public publication on 20 November 2026. Publish the three images with © Chris Page 2026 and source context. This is permission to display the images, not a blanket licence for others to reuse them or verification of slide claims. |
| DESNZ Energy Efficiency Installation Checker | Public documentation and link only. The tool requires sign-in and scheme data access is governed by the DESNZ User Access Policy and relevant sharing agreement. No property data was retrieved. |
| Scotland non-domestic EPC snapshot | The publisher applies OGL v3.0 to non-address fields and separate Royal Mail conditions to address fields. Keep the raw archive local and review rights before including any fields in shared output. |
| WCC public and internal property data | The public February 2026 asset workbook is local. Check coordinate, licence and output-specific conditions. Internal material requires owner review before acquisition or use in the pilot. |
| MHCLG planning consultation and technical draft | The consultation carries the GOV.UK Open Government Licence notice with exceptions. Local technical definition snapshots preserve source attribution and licence metadata where present. Review the terms for individual files and the archive before redistribution. |
| Linked planning documents and discussions | Keep local snapshots and extracts in the ignored source folder. Retain publisher provenance and review each source's terms before reusing it externally. Discussion replies and user account details were excluded from the extracts. |
| Planning pilot reuse audit | Retain schema, checksums and aggregate evidence. The Leeds catalogue states OGL v3.0 with publisher attribution. The Salford legacy catalogue records separate UPRN terms. Check source-specific rights and case fields before sharing an actual planning record. |
| Avon Valley School worked case | The repository holds factual extracts, condition paraphrases, attribution, hashes and source links. Refer to the public register for source documents. Respect the explicit copyright notice on the drawing and the scope of each approval. |
| Avon Valley School review GeoPackage | Local review copy in Git-ignored storage. The red line is derived from approved drawing P08, which retains its copyright. Confirm rights before circulating the derived layer. The OS controls and UPRN point require OS OpenData attribution. |
| QGIS MCP reviewed source | Version 0.15.3 at pinned commit `8a23eb05449d5dcdadaa0df032b6a17b2c859443`. The upstream QGIS plugin is GPL v2 or later; the MCP bridge is MIT. Retain component notices and review obligations for any modified or distributed extension. No upstream code is copied into this repository. See the [security review](sources/qgis-mcp-security-review.md). |
